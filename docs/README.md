# 문서 안내

기능 설계는 `design/`, 운영 점검 항목은 `operations/`에 둔다. 완료한 작업의 검증 기록은 Git 이력에서 확인할 수 있다.

## 현재 제공하는 멜로디 연습

- `멜로디 연습 → 내 악보`에서 MusicXML/MXL, MuseScore, MIDI 파일을 열 수 있다. 악보 전체를 보거나 한 줄씩 편집하고, 조를 바꾸거나 겹음을 동시에 연주할 수 있다. [내 악보 기능 설계](design/uploaded-score-practice.md)
- 자동 생성 멜로디에서는 장조·단조와 무작위·고정 코드 진행을 고를 수 있다. 코드 구성음으로 만든 단선율과 마디 위의 코드명을 보며 연습한다.
- PNG·JPEG 이미지나 PDF에서 높은음자리표 단선율 한 줄을 골라 읽을 수 있다. 여러 쪽짜리 PDF는 연습할 페이지를 먼저 고른다. 마디별 인식 결과를 원본과 대조하고 편집한 뒤 연습한다. [읽을 수 있는 기보와 제한](design/uploaded-score-practice.md#2b--사진pdf-인식-기술-검증)

## 후속 후보

쉼표·임시표·화음 등 더 복잡한 기보는 기기 내 인식 정확도를 검증한 뒤 지원 범위를 넓힌다. [사진·PDF 인식 설계](design/uploaded-score-practice.md#2b--사진pdf-인식-기술-검증)

## 운영 확인

GA 이벤트 수신과 계정 설정, 국가 판정에 쓰는 프록시 헤더, DB 보존 작업, 실기기와 실제 광고 배치는 [운영 체크리스트](operations/pending-checks.md)에서 확인한다.
