# 문서 안내

앞으로 개발할 기능은 `design/`, 아직 실행하지 않은 운영 확인은 `operations/`에 둔다. 완료한 설계·구현 체크리스트·검증 로그를 이곳에 누적하지 않으며 과거 기록은 Git 이력에서 확인한다.

## 남은 개발 기능

- [내 악보 불러오기와 연습](design/uploaded-score-practice.md) — 기기 내 MusicXML/MXL·사진/PDF 처리, 선율·구간 선택과 조옮김, 공통 연주기 연결. 미구현이며 OMR 엔진은 아직 선정하지 않았다.

코드 진행 옵션은 구현·검증을 마쳐 설계 목록에서 제외했다. 장단조·랜덤/고정 진행과 코드 구성음 단선율, 마디 위 코드명은 현재 멜로디 연습에서 제공한다.

업로드 기능은 구조화 파일의 공통 연습 기반을 먼저 만들고, 브라우저 악보 인식의 기술 검증과 사진/PDF 연결을 이어간다. 파일 형식이 달라도 준비 결과 이후의 연주·표시·판정 흐름은 하나로 유지한다.

## 운영 확인

[미실행 운영 확인](operations/pending-checks.md)에는 GA 운영 수신·계정 설정, 국가 판정의 프록시 신뢰 경계, DB 보존 작업, 실기기·실제 광고 확인을 보존한다. 설계 문서 정리를 이유로 아직 실행하지 않은 항목을 완료로 처리하지 않는다.
