# 문서 안내

앞으로 개발할 기능의 설계는 `design/`에, 아직 실행하지 않은 운영 확인은 `operations/`에 둔다.

- [멜로디 코드 진행 생성 설계](design/melody-chord-progression.md) — 장단조와 진행 선택, 코드 구성음 기반 단선율 생성, 마디 위 코드명 표시. 설계 단계이며 미구현이다.
- [미실행 운영 확인](operations/pending-checks.md) — GA 운영 수신·계정 설정, 국가 판정의 프록시 신뢰 경계, DB 보존 작업과 실환경 검증.

완료된 구현 계획·검증 보고서·작업자 인수인계 기록은 정리했다. 과거 기록은 Git 이력에서 확인한다. 설계 문서에는 현재 개발 대상과 결정 사항을 남기고, 완료한 작업의 실행 로그를 누적하지 않는다.
