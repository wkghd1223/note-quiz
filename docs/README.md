# 문서 안내

기능 설계는 `design/`, 운영 점검 항목은 `operations/`에 둔다. 완료한 작업의 검증 기록은 Git 이력에서 확인할 수 있다.

## 현재 제공하는 멜로디 연습

- `멜로디 연습 → 내 악보`에서 MusicXML/MXL, MuseScore, MIDI 파일을 열 수 있다. 악보 전체를 보거나 한 줄씩 편집하고, 조를 바꾸거나 겹음을 동시에 연주할 수 있다. [내 악보 기능 설계](design/uploaded-score-practice.md)
- 자동 생성 멜로디에서는 장조·단조와 무작위·고정 코드 진행을 고를 수 있다. 코드 구성음으로 만든 단선율과 마디 위의 코드명을 보며 연습한다.
- MusicXML·MXL에 적힌 X자 음머리는 전체 보기와 한 줄 보기에 표시된다. 가져온 악보와 생성 멜로디의 편집본에서는 겹음 안에서도 한 음씩 골라 음머리를 기본 또는 X로 바꿀 수 있다. [X자 음머리 표시·편집](design/rhythm-reading.md)
- PNG·JPEG나 PDF에서 연주하거나 노래할 인쇄 오선 한 줄을 고른다. 높은·낮은음자리표, 조표, 박자와 마디별 음·쉼표를 원본과 대조하고, 겹음에서는 연습할 음을 직접 고를 수 있다. [읽을 수 있는 기보와 제한](design/uploaded-score-practice.md#2b--사진pdf-인식-기술-검증)

## 후속 후보

- 같은 악보를 보며 화면이나 스페이스바로 박자를 두드리고, 쉼표에서의 입력도 확인하는 리듬 연습을 설계했다. [리듬 연습 흐름](design/rhythm-reading.md#후속-리듬-연습-흐름)
- 실제 휴대폰 촬영본에서 기울기·조명·인쇄 상태에 따른 정확도와 처리 시간을 측정하는 작업이 남아 있다. [사진·PDF 인식 설계](design/uploaded-score-practice.md#2b--사진pdf-인식-기술-검증)

## 운영 확인

GA 이벤트 수신과 계정 설정, 국가 판정에 쓰는 프록시 헤더, DB 보존 작업, 실기기와 실제 광고 배치는 [운영 체크리스트](operations/pending-checks.md)에서 확인한다.
