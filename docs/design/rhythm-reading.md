# 악보의 X자 음머리 표시·편집과 리듬 읽기

**설계안.** 악기 연주자와 보컬이 악보에 적힌 모양대로 음표를 읽고, 필요한 음에 직접 X자 음머리를 지정할 수 있게 한다. 이 표기는 일반 악보 보기와 편집에도 적용한다. 탭으로 리듬을 연습하는 기능은 같은 악보를 활용하는 후속 단계다.

## 악보에 적힌 음머리와 편집

MusicXML에서 `<notehead>x</notehead>`는 해당 `<note>`의 음머리 모양을 지정한다. 음높이가 있는 `<pitch>`에도, 타악기나 말하는 목소리처럼 음높이가 정해지지 않은 `<unpitched>`에도 쓸 수 있다. MXL은 MusicXML을 압축한 형식이므로 두 파일에 같은 표시 규칙을 적용한다. [음머리 값](https://www.w3.org/2021/06/musicxml40/musicxml-reference/data-types/notehead-value/) · [음높이가 정해지지 않은 음](https://www.w3.org/2021/06/musicxml40/musicxml-reference/elements/unpitched/) · [MXL](https://www.w3.org/2021/06/musicxml40/tutorial/compressed-mxl-files/)

| 사용자가 하는 일 | 설계한 동작 |
| --- | --- |
| 일반 음표와 X 음표가 섞인 XML·MXL 열기 | 파일을 연 직후부터 각 음의 표기를 따른다. 같은 박에 적힌 도·미 중 미에만 X가 있으면 도는 일반 음머리, 미는 원래 높이의 X로 그린다. 전체 보기와 한 줄 보기에서 같은 구별이 보여야 한다. |
| 가져온 악보 또는 생성 멜로디의 편집본에서 음머리 선택 | **음머리 → X**를 누르면 선택한 음의 MusicXML 요소에 `<notehead>x</notehead>`를 기록한다. **기본**을 누르면 해당 음에 지정한 모양을 해제해 보표·악기의 기본 표기를 따른다. 겹음에서는 선택한 구성음 하나에만 적용한다. |
| 편집 후 확인하거나 실행 취소 | 한 줄 보기와 전체 보기에 같은 편집본을 반영한다. 실행 취소는 직전 음머리와 그 속성을 복원한다. 다른 음의 모양과 원본 파일은 보존한다. |

예를 들어 도4의 머리를 X로 바꿔도 음높이 연습의 정답은 도4이고 음가는 그대로다. 무음고 음표는 원본의 악기 정보를 보존하고 `display-step`과 `display-octave`가 가리키는 오선 위치에 그린다. 표시 위치를 생략한 무음고 음표는 보표 가운데에 둔다. 쉼표에는 음머리 선택을 제공하지 않는다. 기존에 `circle-x` 등 다른 모양이 적힌 음도 사용자가 그 음의 모양을 명시적으로 바꿀 때까지 원래 값을 보존한다.

현재 전체 보기에서는 MusicXML에 적힌 X가 표시된다. 한 줄 편집기는 유음고 음표를 타원으로 그린다. 첫 구현 범위는 한 줄 보기에서도 원본 X를 표시하고 선택한 음을 기본 또는 X로 편집하는 것이다. [한 줄 편집기](../../src/features/score-import/ScoreEditor.tsx)

**표시·편집 검증 기준**

- 일반 음, 음높이가 있는 X, 음높이가 없는 X, 쉼표를 섞은 악보를 MusicXML과 MXL로 각각 열어 전체 보기와 한 줄 보기를 대조한다. 두 보기 모두 X의 개수와 오선 위치가 원본과 일치해야 한다.
- 데스크톱과 모바일에서 겹음의 구성음 하나만 X로 바꾼다. 선택한 `<note>`에만 `<notehead>x</notehead>`가 기록되고, 두 보기에서 같은 음이 X로 보여야 한다. 변경 전후의 음높이·음가와 이웃 음의 표기도 비교한다. 기본으로 되돌리기와 실행 취소도 확인한다.
- 생성 멜로디의 편집본에 X를 지정한 뒤 원본과 편집본을 번갈아 열어 각 표기를 확인한다.

## 후속 리듬 연습 흐름

1. **멜로디 → 생성 멜로디**에서 곡을 만들거나 **멜로디 → 내 악보**에서 MusicXML 또는 MXL을 연다. 여러 성부가 있으면 연습할 성부를 고른다.
2. **리듬만 연습**을 고르면 선택한 마디를 보면서 두드릴 수 있다. 일반 음과 X는 각각 악보에 적힌 높이와 모양으로 표시한다. 타격 시점은 음머리 모양과 관계없이 음가, 쉼표, 붙임줄에서 구한다.
3. 예비박이 끝나면 화면의 **탭** 버튼이나 스페이스바를 눌러 연주한다. 메트로놈과 재생선은 선택한 템포를 따른다. 결과에는 맞춘 타격, 놓친 타격, 추가 타격을 보여주고 쉼표에서 누른 위치도 표시한다.
4. 같은 구간을 다시 두드리거나 음높이 연습으로 돌아간다. 이때 같은 곡·성부·구간·속도와 원래 음높이를 다시 쓴다. 리듬 보기는 원본이나 편집본에 덮어쓰지 않는 연습용 표시다.

## 무엇을 한 번으로 세는가

| 악보에 적힌 것 | 연습자가 할 일 |
| --- | --- |
| 음 하나, 또는 동시에 시작하는 겹음 | 시작할 때 한 번 누른다. 점과 음가는 다음 음까지의 간격을 정한다. 버튼을 놓는 시점은 채점에서 제외한다. |
| 같은 음을 두 번 적음 | 각각 누른다. 붙임줄로 이은 경우에는 첫 음만 누른다. |
| 겹음 일부가 먼저 끝나거나 다음 마디까지 이어짐 | 끝나는 음에는 탭이 없다. 이어지는 음과 함께 새 음이 시작하면 그 자리에서 한 번 누른다. |
| 쉼표 | 해당 구간을 비운다. 쉼표를 입력하지 않아도 재생선은 계속 움직인다. |

예를 들어 4/4, ♩=60에서 **4분음표 하나 → 8분음표 둘 → 2분쉼표**라면, 예비박이 끝난 뒤 **0초, 1초, 1.5초**에 누르고 **2초부터 4초까지** 쉰다. 3초에 한 번 더 누른 결과는 ‘3회 일치, 쉼표에서 1회 추가’다.

## 악보 해석과 판정

- 현재 음높이 연습에서는 `<unpitched>`가 있는 구간을 제한한다. 리듬 연습에서는 이 음을 타격으로, `<rest>`를 쉬는 구간으로 읽는다. [가져오기 모델](../../src/features/score-import/model.ts)
- 생성 악보와 가져온 악보 모두 연주 순서에서 **새 음이 시작하는 시각**을 구해 같은 탭 판정을 사용한다. 선택 구간, 못갖춘마디, 마디 안의 템포 변화, 반복 시의 방문 순서를 반영한다. 연습 구간을 붙임줄 뒷음부터 시작하면 첫 음에서 한 번 두드리고, 구간 안에서 이어지는 뒷음은 건너뛴다. [기존 연주 시간 계산](../../src/features/score-import/timeline.ts)
- 하나의 목표와 하나의 탭은 각각 한 번만 짝짓는다. 허용 시간 안에서 가장 가까운 목표에 배정하고, 거리가 같으면 앞 음을 우선한다. 창을 벗어난 목표는 놓침, 남은 탭은 추가 입력이다. 쉼표와 다음 음 경계에서는 음의 허용 창을 먼저 적용해 같은 탭을 정답과 쉼표 실수로 중복 기록하지 않는다. 허용 시간은 기존 멜로디의 시작 시점 판정을 출발점으로 삼고, 빠른 음과 모바일 탭에서 검증한 뒤 정한다.
- 미리 듣기·예비박·일시정지 중 입력은 채점에서 제외한다. 연주 중 스페이스바와 탭 버튼은 누르는 순간 한 번만 입력한다. 키 자동 반복, 터치 뒤의 클릭, 시작 버튼을 누른 동작이 추가 타격을 만들지 않게 한다. 일시정지·재개는 별도 버튼으로 조작하고 입력 필드 등 다른 컨트롤의 키 조작을 보존한다.

## 리듬 연습 검증 기준

| 확인할 상황 | 기대 결과 |
| --- | --- |
| 음가와 쉼표가 같은 마디를 생성 악보·MusicXML·MXL로 연습 | 각 악보의 음머리 모양을 유지하며, 같은 템포에서 필요한 탭 수와 같은 입력의 판정이 일치한다. |
| 음높이가 있는 X 음표·음높이가 없는 X 음표·쉼표가 한 마디에 섞임 | 두 음에는 타격이 있고 쉼표에는 없다. 원본을 다시 보면 각 음의 표기와 음높이가 보존된다. |
| 셋잇단음표, 마디를 넘는 붙임줄, 반복과 템포 변경 | 악보에 맞춰 두드리면 각 시작점이 한 번씩 맞는다. 붙임줄 뒷음이나 겹음 일부의 종료 시점에 가짜 타격이 생기지 않는다. |
| 모바일에서 한 번 터치하거나 데스크톱에서 스페이스바를 길게 누름 | 두 경우 모두 타격 한 번이다. 쉬는 중 추가 탭, 놓친 음, 재시도 결과도 원래 마디와 대조할 수 있다. |

첫 입력 방식은 화면 탭과 스페이스바다. 박수·목소리로 시작 시점을 검출하는 마이크 입력은 기기별 지연과 주변 소음을 별도로 검증할 후속 항목이다.
