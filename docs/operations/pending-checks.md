# 미실행 운영 확인

아래 항목은 운영 계정·배포 환경·실기기에서 아직 확인하지 않은 사항이다. 완료된 로컬 구현이나 자동 테스트의 작업 기록과 구분한다.

## GA 수신과 계정 설정

- [ ] 애플리케이션의 수동 페이지뷰와 Enhanced Measurement의 history 기반 페이지뷰, 다른 태그의 자동 페이지뷰가 중복 수집되지 않는지 확인한다. `send_page_view: false`만으로 history 수집 설정 확인을 대체하지 않는다.
- [ ] 승인된 배포 후 운영자가 통제하는 테스트 브라우저의 이벤트를 DebugView에서 확인한다. 직접 진입·리다이렉트·종류·언어 이동·뒤로/앞으로 이동의 페이지뷰 수, 제목과 유입 정보가 맞는지 확인한다. 설정·기록·결과창의 query/hash 변경이 추가 페이지뷰를 만들지 않아야 한다.
- [ ] 멜로디의 미리 듣기, 준비 실패, 실제 연습 시작, 일시정지·재개, 완료·중단·재시도·이탈을 구분해 수신하는지 확인한다. 기본 연습의 호환 이벤트와 공통 이벤트를 같은 지표에 중복 합산하지 않는다.
- [ ] 실제 보고서에서 사용할 이벤트 속성과 집계값의 custom definition을 등록하고 적용 후 수신을 확인한다. 음표별 답변, 주파수, 녹음, seed·세션 ID·사용자 식별정보를 등록하거나 전송하지 않는다.
- [ ] 같은 기간·요일·시간대와 유입 조건을 맞춰 실제 사용 지표를 비교한다. 로컬 테스트 통과를 운영 수신이나 이용률 개선의 근거로 삼지 않는다.

이벤트와 속성의 현재 정의는 [analytics.ts](../../src/lib/analytics.ts), [analytics-runtime.ts](../../src/lib/analytics-runtime.ts), [멜로디 분석 hook](../../src/features/melody/hooks/useMelodyAnalytics.ts)을 기준으로 확인한다.

## 국가 판정과 DB 보존

- [ ] 배포 프록시/CDN이 어떤 국가·IP 헤더를 덮어쓰는지, 외부 요청이 그 헤더를 위조할 수 없는지 확인한다. 국가 점수 제출의 신뢰 정책은 이 확인 없이 넓히지 않는다.
- [ ] 운영 DB에 필요한 v2 테이블·RPC·권한이 적용돼 있는지 확인한다. 저장소 SQL이 존재한다는 사실로 운영 적용을 가정하지 않는다.
- [ ] `delete_old_leaderboard_country_daily()`의 운영 실행 스케줄·권한·최근 성공 여부를 확인한다. SQL에 정의된 국가 집계 90일·익명 제출 영수증 7일 보존이 실제로 수행되는지 확인한다.

근거: [country.ts](../../src/lib/leaderboard/country.ts), [Supabase 연결](../../src/lib/leaderboard/supabase.ts), [leaderboard.sql](../../supabase/leaderboard.sql).

## 실환경 검증

- [ ] 실제 목소리·악기·물리 마이크, 스피커 또는 Bluetooth 환경의 검출·청취·지연을 확인한다. 합성 PCM이나 가상 마이크 결과와 구분한다.
- [ ] 모바일 실기기와 Safari·Firefox의 오디오·화면·성능을 확인한다.
- [ ] 실제 광고 소재의 주요 배치에서 입력·설정·결과창·푸터가 가려지지 않는지 확인한다. 모의 광고나 일부 관찰한 소재를 전체 광고 배치의 검증으로 확대하지 않는다.
